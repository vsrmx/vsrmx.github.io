⚠ Always use the correct die — MQS requires PA-20 or equivalent micro die. Using PA-09 on MQS will destroy the terminal. The VAG tool numbers are VAG special service tools (SST); Rennsteig equivalents are the most common workshop alternative.

Seal insertion tools
Seal typeTool / method
1.5mm wire seals (3.9mm)VAG 1978/2 or blunt probe — push seal onto wire before crimping terminal, then seat into cavity
2.8mm wire seals (5.6mm)VAG 1978/3 or fingers — larger seal, easier to seat manually
4.8mm wire seals (9.0mm)Push fit by hand — large enough to seat without tools
Superseal integral sealsNo separate tool — seals are pre-installed in each cavity
Cavity plugs (unused cavities)Push fit — 357972841 (2.8mm green) or 357972841 (1.5mm)

Always slide the wire seal onto the wire before crimping the terminal. The seal should sit against the terminal insulation grip. Pushing a seal over a pre-crimped terminal will damage the seal.

Connector Identification Guide

Not sure what connector you're looking at? Work through these steps to narrow it down.

Step 1 — Count the pins & measure pitch
Pin pitchTerminal familyTypical application
~2.0mm (very fine)MQS 0.63mmInstrument cluster, airbag sub-looms, data signals
~2.5mm (fine)MCON 1.2 / MLK 1.2MQB/MLB sensor sub-looms, body modules
~3.5mm1.5mm Micro TimerMost engine bay sensors — the most common VAG connector size
~5.0mm2.8mm JPT / VW Tab / KOSTAL SLKSolenoids, injectors (older), actuators, higher-current sensors
~7.5mm4.8mm SPTHigh-current: starter, fans, fuse box feeds
CoaxialFAKRA / SMBAntenna connections — GPS, DAB, video
Step 2 — Identify the locking mechanism
Locking typeLikely family
Side tab latch (press sideways)Micro Timer, JPT, VW Tab, Econoseal
Sliding secondary lock (slides up from below)Micro Timer II — distinctive feature
Rotating lever (pull lever to release)Bosch Motronic ECU connectors (55/60-pin)
Quadlock lever (push to lock, pull to release)MQS — blue or yellow CPA lever
Red secondary lock strip (slides across back)AMP Superseal — always red on this family
No visible latch — friction fit onlyOBD-II DLC, pre-OBD 2×2, coding plugs
Snap latch (squeeze sides)FAKRA coaxial connectors
Step 3 — Housing colour clues
ColourWhat it often means
Yellow CPA leverAirbag / SRS circuit — treat with caution, disconnect battery first
Red secondary lockAMP Superseal 1.5 — IP67 sealed, outdoor/wheel arch application
Beige / tan housingFAKRA code Z — GPS antenna
Blue housing / leverFAKRA code B (DAB antenna) or MQS data line CPA
Green housingOften Econoseal door loom (driver side) or Micro Timer variant

Pin profileTerminal familyNotes
